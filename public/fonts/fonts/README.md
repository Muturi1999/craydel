# Font Files

Please place your "Twentieth Century for Kenmore N Medium" font file in this directory.

Supported file formats:
- `.ttf` (TrueType Font)
- `.otf` (OpenType Font)
- `.woff2` (Web Open Font Format 2) - Recommended
- `.woff` (Web Open Font Format)

**File naming:**
Name your font file as one of the following:
- `TwentiethCenturyKenmoreNMedium.ttf`
- `TwentiethCenturyKenmoreNMedium.otf`
- `TwentiethCenturyKenmoreNMedium.woff2`
- `TwentiethCenturyKenmoreNMedium.woff`

The system will automatically detect and use the available font file format.
